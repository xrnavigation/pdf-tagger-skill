# Example: form

A one-page volunteer sign-up form generated by `make_pdf.py` (reportlab for
the static text with an embedded TTF; pikepdf adds the AcroForm). The widget
appearance streams are pure vector paths — no fonts — which keeps PDF/UA
font-embedding checks trivially clean. Demonstrates:

- a `Form` structure element with an OBJR for every widget, each widget
  getting `/StructParent` and a ParentTree entry;
- `/TU` accessible names on all six fields (what a screen reader announces);
- reading-order interleaving in the TREE: a text field comes *after* its
  visible label (`node('P_name', M, F('name'))`), a checkbox comes *before*
  its label (`node('P_news', F('newsletter'), M)`), matching the visual
  layout;
- the engine also sets `/Tabs /S` so keyboard tab order follows the
  structure.

Result: zero-pixel render diff; veraPDF PDF/UA-1 PASS.
