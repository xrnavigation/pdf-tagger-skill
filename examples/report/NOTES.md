# Example: report

A one-page report generated by `make_pdf.py` (reportlab/platypus, embedded
TTF). Demonstrates:

- one `H1`, two `H2` sections, body paragraphs, a small footer paragraph;
- a genuine data table tagged `Table/TR/TH/TD` with `Scope=Column` headers —
  cell assignment is pure coordinates: one y-band per row, x-splits at the
  column edges;
- the table's ruled grid is path content, so the engine marks it `/Artifact`
  automatically — no config needed;
- platypus puts every text object inside `q cm ... Q`, which the engine
  handles by closing marked content at `q`/`Q` boundaries.

Result: zero-pixel render diff; veraPDF PDF/UA-1 PASS.
